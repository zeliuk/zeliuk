## 📱 Proyectos

### [Marcador de Tenis](https://play.google.com/store/apps/details?id=xyz.zeliuk.apptenis)

Aplicación multiplataforma desarrollada con **Flutter**, con backend en **Python y FastAPI**, persistencia de datos mediante **Firebase / Firestore** y despliegue con **Docker en Render**.

Incluye versión para **Wear OS**, widget Android, estadísticas detalladas de partidos y funcionalidades basadas en IA para el análisis de resultados.

**Tecnologías:** Flutter, Dart, Python, FastAPI, Firebase, Firestore, Docker, Render, Wear OS y Android Widgets.

### [Messi Dress-Up](http://messi.zeliuk.xyz)

Proyecto interactivo en tiempo real en el que un dispositivo móvil controla la vestimenta mostrada en una pantalla.

La comunicación web ↔ móvil se realiza mediante código QR y sincronización con **Crossbar.io**, utilizando el protocolo WAMP, Pub/Sub, WebSockets y AutobahnJS.

**Tecnologías:** HTML, CSS, JavaScript, WebSockets, Crossbar.io, WAMP, Docker, Google Cloud y QR Sync.
